# MACS 401 EODA Final Project
### Blue ROV2 Trajectory data by Riley Quaschnick 

### Goals
My project focuses on working with BlueROV2 trajectory data to get a better sense of how to efficiently operate a BlueROV2. 

### Motivation
I have been interested in operating ROVs for almost ten years. With my capstone project at WWU, I have the opportunity to operate an inspection class ROV. While my previous experience includes building and operating DIY PVC made ROVs, this project will enhance my ability as a pilot. Since this ROV is different than the ones I have previously encountered, it will further my understanding of the physics included with operating an inspection class ROV. 

### Data Set
I will be using a trajectory dataset found on GitHub. These can be accessed via Pandas to read CSV files. 
https://github.com/oceansystemslab/Bluerov2_trajectory_dataset

### Analysis Methods 
In this analysis, I will have to load CSV files into python via Pandas. I will also clean up any data that will not be useful in my project. Finally, I will be working with interger data that using Pandas and MatPlotLib, I can make velocity and possibly time series graphs.
